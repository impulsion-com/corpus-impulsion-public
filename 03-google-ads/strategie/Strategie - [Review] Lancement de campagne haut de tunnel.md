# Lancement de campagne haut du tunnel

> **Plateforme :** Google Ads
> **Catégorie :** Strategie
> **Type :** Checklist
> **Mis à jour :** 2026-05-07

## Objectif

Valide que les campagnes Display, Video et Demand Gen sont correctement configurées avant le lancement, couvrant le ciblage, les exclusions, les créatives et les paramètres.

---

## Ce que cette checklist valide

Cette checklist confirme :

- Le ciblage par audience est correctement configuré
- Les exclusions de contenu et les paramètres de sécurité de marque sont en place
- Les composants créatifs respectent les spécifications
- Les paramètres de campagne correspondent à l'objectif
- Les cascades d'exclusion empêchent le gaspillage de dépenses

Cette checklist ne couvre **PAS** :

- La validation de la qualité du texte publicitaire (Voir : [Headline Quality Checklist](<../search/Search - [Review] Qualité des titres.md>), [Description Quality Checklist](<Strategie - [Review] Qualité des descriptions.md>))
- La validation de la configuration des segments d'audience (Voir : [Audience Targeting Launch Checklist](<../audiences/Audiences - [Review] Lancement du ciblage par audience.md>))
- La validation de la qualité des créatives image ou vidéo (Voir : [Image Creative Quality Checklist](<../creatives/Creatives - [Review] Qualité des créatives image.md>), [Video Creative Quality Checklist](<../creatives/Creatives - [Review] Qualité des créatives vidéo.md>))

---

## Quand l'utiliser

Exécuter cette checklist :

- Avant le lancement de toute campagne Display, Video ou Demand Gen
- Lors de la réactivation d'une campagne haut du tunnel en pause
- Lors des audits trimestriels des campagnes haut du tunnel

---

## Checklist

### Structure de campagne

- [ ] L'objectif de campagne correspond à l'objectif business (objectif documenté avec une cible KPI mesurable)
- [ ] Le type de campagne correspond à l'objectif (Video pour la notoriété, Demand Gen pour les conversions)
- [ ] Le nommage de campagne suit la convention du compte
- [ ] Le budget est défini et approprié pour la taille d'audience
- [ ] Les dates de début et fin sont correctes (si applicable)

### Configuration du ciblage

- [ ] Les audiences sont ajoutées avec le bon mode de ciblage (Ciblage pour le remarketing, Observation pour la collecte de données sur les segments de prospection)
- [ ] Les segments d'audience correspondent au tier de campagne (remarketing, prospection ou notoriété)
- [ ] La bonne fonctionnalité d'expansion est définie : ciblage optimisé (Display, Video Ventes/Leads/Trafic, Demand Gen) ou expansion d'audience (Video Considération/Notoriété)
- [ ] Fonctionnalité d'expansion DÉSACTIVÉE pour les campagnes de remarketing, définie intentionnellement pour la prospection
- [ ] La taille d'audience est suffisante pour la diffusion (1 000+ utilisateurs pour le remarketing, 5 000+ pour les listes sources d'audience similaire)
- [ ] Le ciblage géographique est correct
- [ ] Le ciblage linguistique est correct
- [ ] Les ajustements de ciblage par appareil sont définis (si applicable)

### Ciblage de contenu (Display/Video uniquement)

- [ ] Les emplacements sont vérifiés et pertinents (si ciblage par emplacement)
- [ ] Les sujets sont appropriés pour l'audience (si ciblage par sujet)
- [ ] Les mots-clés de contenu sont thématiques et limités à 5-20 par groupe d'annonces (si utilisés)
- [ ] Le ciblage de contenu et le ciblage par audience sont combinés intentionnellement (logique ET comprise)

### Exclusions (Obligatoire)

- [ ] Les convertis récents sont exclus (7-90 jours selon le cycle de vente)
- [ ] Les apps mobiles sont exclues (sauf campagne axée sur les apps)
- [ ] Le contenu fait pour les enfants est exclu
- [ ] Les domaines parqués et pages d'erreur sont exclus
- [ ] Les campagnes de prospection excluent toutes les audiences de remarketing
- [ ] Les paramètres de pertinence de contenu au niveau compte sont configurés

### Sécurité de marque (Obligatoire)

- [ ] Les catégories de contenu sensible sont vérifiées et les exclusions appliquées
- [ ] Le type d'inventaire est défini de manière appropriée (Standard minimum pour la Video)
- [ ] Les libellés de contenu numérique sont vérifiés (DL-MA exclu pour la plupart des marques)
- [ ] La liste d'exclusion d'emplacements inclut les sites de faible qualité connus

### Composants créatifs

- [ ] Un nombre suffisant de variations créatives est importé (3+ par format)
- [ ] Toutes les tailles de composants requises sont incluses (Display : voir Image Creative Reference)
- [ ] Les durées vidéo sont appropriées pour l'objectif (notoriété : <15s, considération : 15-60s)
- [ ] Les créatives correspondent à la température de l'audience (audiences froides voient le message problème/notoriété, audiences chaudes voient le message offre/urgence)
- [ ] Les URLs des Landing Pages sont correctes et fonctionnelles
- [ ] L'appel à l'action correspond à l'objectif de campagne

### Enchères et budget

- [ ] La stratégie d'enchères correspond à l'objectif et aux attentes de volume de la campagne
- [ ] Le CPA/ROAS cible est défini sur la base de l'économie unitaire (si applicable)
- [ ] Le budget est suffisant pour sortir de la phase d'apprentissage (50+ conversions/mois pour Demand Gen)
- [ ] Les ajustements d'enchères sont définis intentionnellement (si utilisation de stratégies manuelles ou améliorées)

### Suivi et mesure

- [ ] Le suivi des conversions est vérifié fonctionnel
- [ ] Les bonnes actions de conversion sont sélectionnées pour l'optimisation de campagne
- [ ] La fenêtre de conversion après affichage est définie de manière appropriée
- [ ] Le modèle d'attribution est cohérent avec les autres campagnes

### Vérification finale

- [ ] L'aperçu de campagne affiche les annonces correctement
- [ ] Aucune violation de politique signalée
- [ ] La date de lancement et le budget sont confirmés avec la partie prenante (si applicable)

---

## Vérifications spécifiques par campagne

### Campagnes Display

- [ ] Les annonces Display responsives ont tous les types de composants (images, logos, titres, descriptions)
- [ ] Le flux de produits de remarketing dynamique est connecté (si remarketing e-commerce)
- [ ] Le plafond de répétition est défini (3-5 impressions/utilisateur/jour typique)

### Campagnes Video

- [ ] Le format vidéo correspond au sous-type de campagne (désactivable vs. non désactivable)
- [ ] La bannière associée est importée (si applicable)
- [ ] Le plafond de répétition est défini (2-3 impressions/utilisateur/jour typique)
- [ ] La chaîne YouTube est liée (pour la construction d'audience)

### Campagnes Demand Gen

- [ ] Composants image ET vidéo inclus (pour une portée maximale)
- [ ] Les segments d'audience similaire utilisent des listes sources de haute qualité : convertis ou clients à haute valeur, pas tous les visiteurs (si prospection)
- [ ] La portée de l'audience similaire est définie sur Équilibré initialement (Étroit pour les budgets serrés)
- [ ] Si ciblage optimisé ACTIVÉ : conscient que Google peut diffuser au-delà des sélections démographiques
- [ ] Le flux de produits est connecté pour les créatives dynamiques (si e-commerce)
