# Sélectionner une stratégie d'enchères

> **Plateforme :** Google Ads
> **Catégorie :** Enchères
> **Type :** SOP
> **Mis à jour :** 2026-05-07

## Phase 1️⃣: Confirmer l'objectif d'optimisation

### 1.1 Mapper les objectifs business aux objectifs d'optimisation

Examinez les objectifs de campagne établis dans [SOP - Definir les objectifs et KPIs de campagne](<../strategie/Strategie - Définir les objectifs et KPIs de campagne.md>). Identifiez quel objectif d'optimisation correspond à votre objectif principal.

| Objectif business | Objectif Google Ads | Objectif d'optimisation |
|---------------|----------------|----------------------|
| Notoriété de marque, entrée sur le marché | Maximiser la visibilité | **Visibilité** |
| Trafic du site web, construction d'audience | Maximiser les clics | **Trafic** |
| Génération de leads (prospects), achats, inscriptions | Maximiser le volume de conversions | **Conversions** |
| Croissance du revenu, objectifs ROAS, profit | Maximiser la valeur de conversion | **Valeur** |

### 1.2 Confirmer que l'objectif correspond à la méthode KPI

Recoupez votre objectif d'optimisation avec le KPI principal issu de vos objectifs :

| KPI principal | Objectif d'optimisation attendu |
|-------------|-------------------------------|
| Taux d'impressions | Visibilité |
| Clics, CTR | Trafic |
| CPA, conversions | Conversions |
| ROAS, valeur de conversion, POAS | Valeur |

Si le KPI principal et l'objectif d'optimisation ne correspondent pas, revoyez [SOP - Definir les objectifs et KPIs de campagne](<../strategie/Strategie - Définir les objectifs et KPIs de campagne.md>) avant de continuer.

## Phase 2️⃣: Évaluer la maturité des données

### 2.1 Déterminer le statut des données du compte

Classez le compte dans l'un des trois états :

| État des données | Définition | Implication |
|------------|-----------|-------------|
| **Nouveau compte (zéro donnée)** | Aucune donnée de conversion historique dans le compte | Stratégies d'enchères intelligentes n'a aucun signal pour apprendre : commencez avec une stratégie de collecte de données ou utilisez une stratégie d'enchères de portefeuille pour mutualiser les signaux |
| **Données minimales (15-29/mois)** | 15-29 conversions sur les 30 derniers jours pour ce type de campagne | Minimum absolu pour les stratégies d'enchères basées sur les conversions : attendez-vous à une forte volatilité et à des périodes d'apprentissage plus longues |
| **Données fonctionnelles (30-49/mois)** | 30-49 conversions sur les 30 derniers jours pour ce type de campagne | Stratégies d'enchères intelligentes peut fonctionner avec une stabilité modérée pour le CPA cible ; le ROAS cible nécessite encore plus de données |
| **Données suffisantes (50+/mois)** | 50+ conversions sur les 30 derniers jours pour ce type de campagne | Stratégies d'enchères intelligentes a assez de signaux pour une optimisation fiable, y compris le ROAS cible |

> ⚠️ **Seuils de volume de conversions :** 15/mois = minimum absolu (forte volatilité), 30/mois = fonctionnel pour le CPA cible (stabilité modérée), 50/mois = recommandé pour toutes les stratégies y compris le ROAS cible. En dessous de 15, les stratégies basées sur les conversions n'auront pas assez de signal pour optimiser efficacement.

### 2.2 Évaluer la familiarité du ciblage

Déterminez si la campagne cible un territoire familier ou non familier :

| Facteur | Familier | Non familier |
|--------|----------|------------|
| **Keywords/audiences** | Performances éprouvées issues de campagnes existantes | Nouveaux thèmes de keywords, audiences non testées |
| **Zone géographique** | Marché existant | Nouveau marché ou nouvelle région |
| **Offre** | Produit/service établi | Nouvelle offre, tarification non testée |

Un ciblage non familier augmente le risque. En combinant zéro donnée avec un ciblage non familier, optez par défaut pour une stratégie de collecte de données conservatrice.

### 2.3 Vérifier la connaissance de la niche

Si vous avez une connaissance approfondie de la niche (CPC attendus, taux de conversion typiques, paysage concurrentiel), vous pouvez définir des cibles initiales mieux informées. Si la niche est peu familière, appuyez-vous sur des benchmarks (analyses comparatives) plus larges et prévoyez une période d'apprentissage plus longue.

### 2.4 Enregistrer l'évaluation de maturité des données

| Champ | Valeur |
|-------|-------|
| État des données du compte | (Zéro / Sous le seuil / Suffisant) |
| Conversions sur les 30 derniers jours | |
| Familiarité du ciblage | (Familier / Non familier) |
| Niveau de connaissance de la niche | (Approfondi / Modéré / Faible) |
| Stratégie d'enchères de portefeuille disponible | (Oui / Non) |

## Phase 3️⃣: Sélectionner la stratégie via l'arbre de décision

### 3.1 Ouvrir le bon arbre de décision

Ouvrez le [Bid Strategy Selection Reference](<Enchères - Sélection de stratégie d'enchères.md>) et accédez à l'arbre de décision correspondant à votre type de campagne :

| Type de campagne | Section de l'arbre de décision |
|--------------|----------------------|
| Search | Arbre de décision campagne Search |
| Shopping standard | Arbre de décision campagne Shopping |
| Performance Max | Arbre de décision campagne PMax |
| Display | Arbre de décision campagne Display |
| Video | Arbre de décision campagne Video |
| Demand Gen | Arbre de décision campagne Demand Gen |

### 3.2 Dérouler l'arbre de décision

Suivez l'arbre de décision de haut en bas. À chaque nœud, utilisez les éléments recueillis dans les Phases 1 et 2 pour déterminer la bonne branche.

L'arbre de décision prend en compte :

1. Votre objectif d'optimisation (issu de la Phase 1)
2. Votre état de maturité des données (issu de la Phase 2)
3. Les contraintes propres au type de campagne

### 3.3 Documenter la stratégie sélectionnée

Notez le résultat de l'arbre de décision :

| Champ | Valeur |
|-------|-------|
| Stratégie d'enchères sélectionnée | |
| Justification (chemin dans l'arbre de décision) | |
| Est-ce une stratégie de collecte de données ? | (Oui / Non) |
| Stratégie de migration prévue (le cas échéant) | |
| Déclencheur de migration (le cas échéant) | |

> 💡 **Si l'arbre de décision recommande une stratégie de collecte de données,** c'est un point de départ temporaire. Documentez la stratégie cible vers laquelle vous prévoyez de migrer une fois les seuils de données atteints.

## Phase 4️⃣: Configurer et documenter

### 4.1 Définir la stratégie d'enchères dans Google Ads

Ouvrez Google Ads (ou Google Ads Editor) et configurez la stratégie d'enchères sélectionnée pour la campagne.

1. Accédez aux paramètres de la campagne
2. Sélectionnez la stratégie d'enchères issue de la Phase 3
3. Définissez la cible initiale (le cas échéant, voir 4.2)
4. Enregistrez la configuration

### 4.2 Définir les cibles initiales

Si la stratégie sélectionnée nécessite une cible (CPA cible, ROAS cible), définissez-la selon les règles suivantes :

| Stratégie | Règle de cible initiale | Exemple |
|----------|-------------------|---------|
| CPA cible | Définir au niveau ou légèrement au-dessus du CPA moyen des 30 derniers jours | CPA moyen de 45 € : définir le CPA cible à 45-50 € |
| ROAS cible | Définir au niveau ou légèrement en dessous du ROAS moyen des 30 derniers jours | ROAS moyen de 450 % : définir le ROAS cible à 400-450 % |
| Maximiser les conversions (sans cible) | Aucune cible nécessaire | Laisser la cible vide |
| Maximiser la valeur de conversion (sans cible) | Aucune cible nécessaire | Laisser la cible vide |
| CPC manuel | Définir le CPC max selon les unit economics et le taux de conversion attendu | CPA max 50 €, CVR 3 % : CPC max = 1,50 € |

> ⚠️ **Ne définissez pas de cibles agressives au lancement :** Démarrer avec une cible nettement meilleure que la performance historique force l'algorithme dans une période d'apprentissage contrainte. Laissez-le d'abord apprendre aux niveaux de performance actuels, puis resserrez les cibles progressivement.

Pour les nouveaux comptes sans données historiques, utilisez les unit economics pour calculer votre CPA de rentabilité ou votre ROAS minimum, puis définissez la cible initiale 10-20 % plus conservatrice que le seuil de rentabilité.

### 4.3 Briefer les parties prenantes sur la période d'apprentissage

Communiquez les éléments suivants aux parties prenantes concernées :

| Sujet | Ce qu'il faut communiquer |
|-------|-------------------|
| **Stratégie sélectionnée** | Le nom de la stratégie et pourquoi elle a été choisie |
| **Période d'apprentissage** | Environ deux cycles de conversion de performance volatile sont à prévoir (Voir : [Stratégies d'enchères intelligentes Mechanics Reference](<Enchères - Mécanismes des stratégies d'enchères intelligentes.md>)) |
| **Ce qu'il ne faut pas faire** | Ne pas faire de changements pendant la période d'apprentissage (changements de budget, changements de ciblage, ajustements d'enchères) |
| **Quand attendre la stabilité** | Une fois la période d'apprentissage terminée, la performance devrait se normaliser |
| **Plan de migration** | Si vous démarrez avec une stratégie de collecte de données, expliquez la migration prévue et le calendrier |

### 4.4 Documenter le plan de migration

Si la stratégie sélectionnée est un point de départ de collecte de données, documentez la marche à suivre :

| Champ | Valeur |
|-------|-------|
| Stratégie actuelle (de départ) | |
| Stratégie cible (de destination) | |
| Déclencheur de migration | (ex : 50+ conversions en 30 jours) |
| Calendrier prévu jusqu'à la migration | |
| Qui surveille et exécute la migration | |

### 4.5 Checklist finale

- [ ] La stratégie d'enchères est définie dans Google Ads
- [ ] La cible initiale est configurée (le cas échéant)
- [ ] La cible n'est pas plus agressive que les moyennes historiques
- [ ] Les parties prenantes sont briefées sur la période d'apprentissage
- [ ] Le plan de migration est documenté (si stratégie de collecte de données)
- [ ] La campagne n'est pas en pause ni à l'état de brouillon

### Validation et critères de complétion

Cette SOP est terminée quand :

- [ ] L'objectif d'optimisation est confirmé et documenté
- [ ] L'évaluation de la maturité des données est complète
- [ ] La stratégie d'enchères est sélectionnée via l'arbre de décision avec une justification documentée
- [ ] La stratégie est configurée dans Google Ads avec des cibles initiales appropriées
- [ ] Les parties prenantes sont briefées sur les attentes de la période d'apprentissage
- [ ] Le plan de migration est documenté (le cas échéant)
- [ ] Exécuter la [Bid Strategy Health Checklist](<Enchères - [Review] Santé de la stratégie d'enchères.md>) et valider tous les points applicables

### Passerelle de sortie

Une fois que la stratégie d'enchères est configurée et que la campagne est active :

| Délai | Action |
|-----------|--------|
| Jours 1-14 | Surveiller le statut de la période d'apprentissage. Ne faire aucun changement sauf en cas de problème critique. |
| Jour 14+ | Confirmez que la période d'apprentissage est terminée. Analysez la performance initiale par rapport aux cibles. |
| Jour 30+ | Évaluer si les seuils de collecte de données sont atteints. Si oui, exécuter la migration vers la stratégie cible. |
| En continu | Surveiller la santé de la stratégie d'enchères à l'aide de la [Bid Strategy Health Checklist](<Enchères - [Review] Santé de la stratégie d'enchères.md>) à une cadence régulière. |

**En cas de problème :**

| Problème | Rediriger vers |
|-------|----------|
| La période d'apprentissage se réinitialise à répétition | Vérifier les changements perturbateurs : consulter [Stratégies d'enchères intelligentes Mechanics Reference](<Enchères - Mécanismes des stratégies d'enchères intelligentes.md>) |
| Performance nettement pire que prévu | Vérifier le suivi des conversions, revoir l'évaluation de la maturité des données |
| Le volume de conversions passe sous le seuil minimum | Envisager de consolider les campagnes, de revenir à une stratégie de collecte de données, ou de mutualiser dans une stratégie d'enchères de portefeuille |
| Une partie prenante veut passer outre la stratégie | Revenir à la Phase 1 pour confirmer que les objectifs d'optimisation sont toujours alignés |

### FAQ

**Q : Que faire si ma campagne a moins de 15 conversions par mois ?**

R : Les stratégies d'enchères basées sur les conversions (Maximiser les conversions, CPA cible, ROAS cible) n'auront pas assez de signal. Utilisez le CPC manuel comme stratégie de collecte de données jusqu'à atteindre au moins 15 conversions par mois. Sinon, consolidez les campagnes ou utilisez une stratégie d'enchères de portefeuille pour mutualiser les données de conversion entre plusieurs campagnes.

**Q : Dois-je commencer avec Maximiser les conversions ou CPA cible ?**

R : Si vous avez suffisamment de données historiques (50+ conversions/mois) et un CPA cible clair issu de vos unit economics, commencez avec le CPA cible. Si les données sont limitées ou que vous établissez encore une performance de référence, commencez avec Maximiser les conversions (sans cible) pour laisser l'algorithme collecter des données, puis migrez vers le CPA cible une fois que vous avez une moyenne fiable.

**Q : Combien de temps dois-je attendre avant de resserrer les cibles ?**

R : Attendez au moins deux périodes d'apprentissage complètes (14-28 jours) après la configuration initiale avant d'ajuster les cibles. Pour resserrer, procédez par incréments de 10-15 % à la fois, et laissez une période d'apprentissage complète entre chaque ajustement.

### Erreurs fréquentes

| Erreur | Pourquoi ça arrive | Comment l'éviter |
|---------|----------------|--------------|
| Définir des cibles agressives au lancement | Vouloir atteindre le CPA/ROAS idéal immédiatement | Démarrer au niveau ou près des moyennes historiques, resserrer progressivement |
| Choisir CPA cible/ROAS cible avec des données insuffisantes | Sauter l'évaluation de la maturité des données | Compléter la Phase 2 avant de sélectionner une stratégie |
| Faire des changements pendant la période d'apprentissage | Impatience face à la performance initiale volatile | Briefer les parties prenantes en amont, poser les attentes sur la période d'apprentissage (deux cycles de conversion) |
| Pas de plan de migration pour les stratégies de collecte de données | Traiter la stratégie de départ comme permanente | Toujours documenter la stratégie cible et le déclencheur de migration en Phase 4 |
| Ignorer les contraintes propres au type de campagne | Supposer que toutes les stratégies fonctionnent pour tous les types | Utiliser l'arbre de décision spécifique au type de campagne en Phase 3 |
