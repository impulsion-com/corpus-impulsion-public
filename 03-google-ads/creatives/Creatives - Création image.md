# Création image

> **Plateforme :** Google Ads
> **Catégorie :** Strategie
> **Type :** SOP
> **Mis à jour :** 2026-05-07

## Objectif

Documente les spécifications des annonces image, les directives de qualité et les exigences techniques pour les campagnes Display, Demand Gen et Performance Max.

---

## Ce que couvre cette fiche / Ce qu'elle ne couvre PAS

**Cette fiche :**

- Documente les spécifications d'image par type de campagne
- Fournit les exigences de ratio et de dimensions
- Liste les directives de logo et les bonnes pratiques
- Couvre les règles de composition et les éléments interdits

**Cette fiche ne couvre PAS :**

- Valider la qualité des images (Voir : [Image Creative Quality Checklist](<Creatives - [Review] Qualité des créatives image.md>))
- Configurer les paramètres d'optimisation des assets (Voir : [Asset Optimization Control Guidelines](<../pmax/Pmax - Contrôle de l'optimisation des assets.md>))
- Fournir les spécifications vidéo (Voir : [Video Creative Reference](<../video/Video - Création vidéo.md>))
- Couvrir la structure de campagne (Voir : SOP de campagne pertinente)

## Aide-mémoire : spécifications des images

### Campagnes Display

| Ratio | Dimensions (px) | Priorité | Cas d'usage |
| --- | --- | --- | --- |
| Paysage (1.91:1) | 1200 × 628 | Requis | Emplacements Display standard |
| Carré (1:1) | 1200 × 1200 | Requis | Emplacements natifs, style social |
| Portrait (9:16) | 900 x 1600 | Recommandé | Emplacements mobile-first |

### Campagnes Demand Gen

| Ratio | Dimensions (px) | Priorité | Cas d'usage |
| --- | --- | --- | --- |
| Paysage (1.91:1) | 1200 × 628 | Requis | YouTube, Discover, Gmail |
| Carré (1:1) | 1200 × 1200 | Requis | Emplacements de flux |
| Portrait (4:5) | 960 × 1200 | Recommandé | YouTube Shorts, mobile |
| Vertical (9:16) | 1080 × 1920 | Recommandé | YouTube Shorts |

### Campagnes Performance Max

| Ratio | Dimensions (px) | Priorité | Cas d'usage |
| --- | --- | --- | --- |
| Paysage (1.91:1) | 1200 × 628 | Requis | Search, Display, Discover |
| Carré (1:1) | 1200 × 1200 | Requis | Tous les emplacements |
| Portrait (4:5) | 960 × 1200 | Fortement recommandé | Mobile, YouTube |
| Vertical (9:16) | 1080 × 1920 | Recommandé | YouTube Shorts |

---

## Quantité d'images recommandée

| Type de campagne | Minimum | Recommandé | Maximum |
| --- | --- | --- | --- |
| Display | 1 par ratio | 3-5 par ratio | 15 au total |
| Demand Gen | 3 au total | 5-10 au total | 20 au total |
| Performance Max | 3 au total | 10-15 au total | 20 au total |

> 💡 **Pourquoi plus d'images ?** Plus de variations = plus de tests = meilleure optimisation. Google teste les combinaisons à travers les emplacements.

## Exigences techniques des fichiers

| Exigence | Spécification |
| --- | --- |
| Format | JPG, PNG (PNG recommandé pour les logos, les textes superposés) |
| Taille de fichier | Max 5 Mo par image |
| Résolution | 1200 px sur le côté le plus long recommandé |
| Espace colorimétrique | RGB |
| Pas d'animation | Images statiques uniquement (utilisez des assets vidéo pour le mouvement) |

## Spécifications du logo

### Logo carré (1:1)

| Spécification | Exigence |
| --- | --- |
| Dimensions | 1200 × 1200 px (recommandé) |
| Minimum | 128 × 128 px |
| Fond | Transparent ou uni (blanc/couleur de marque) |
| Contenu | Logo uniquement, pas de slogans |

### Logo paysage (4:1)

| Spécification | Exigence |
| --- | --- |
| Dimensions | 1200 × 300 px (recommandé) |
| Minimum | 512 × 128 px |
| Fond | Transparent ou uni |
| Contenu | Logo avec nom de marque acceptable |

### Bonnes pratiques pour les logos

| À faire | À ne pas faire |
| --- | --- |
| Utiliser le logo officiel de la marque | Utiliser des versions obsolètes du logo |
| Assurer la lisibilité en petite taille | Ajouter des éléments décoratifs |
| Utiliser un fond transparent quand possible | Utiliser des fonds complexes |
| Tester à 50×50 px pour la visibilité | Supposer un affichage en grande taille |
| Inclure un espacement/zone de sécurité | Rogner le logo jusqu'aux bords |

## Directives de composition d'image

### La règle des tiers

Divisez l'image en 9 parties égales avec 2 lignes horizontales et 2 lignes verticales. Placez les éléments clés le long de ces lignes ou à leurs intersections.

```
┌─────┬─────┬─────┐
│     │     │     │
├─────┼─────┼─────┤
│     │ CLÉ │     │
├─────┼─────┼─────┤
│     │     │     │
└─────┴─────┴─────┘
```

### Zones de sécurité

| Zone | Indication |
| --- | --- |
| Centre 80% | Sûr pour le contenu critique (produit, visages, texte) |
| Bord extérieur 10% | Peut être rogné sur certains emplacements |
| Coins | Éviter les éléments critiques (des boutons de surcouche peuvent apparaître) |

### Principes de composition

| Principe | Mise en oeuvre |
| --- | --- |
| Point focal unique | Un sujet clair, pas d'éléments en compétition |
| Contraste élevé | Le sujet se détache du fond |
| Texte minimal | Laissez l'image faire le travail (texte dans les titres plutôt) |
| Fonds épurés | Simple > chargé ; couleurs unies ou motifs subtils |
| Photographie réelle | Les images authentiques surpassent le stock |
| Personnes quand pertinent | Les visages génèrent de l'engagement (quand approprié) |

## Texte sur les images

### Politique de Google sur le texte

Google recommande **un texte minimal ou pas de texte** sur les images. Les images chargées de texte :

- Peuvent être refusées
- Performent souvent moins bien (encombrées, difficiles à lire)
- Rivalisent avec le texte d'annonce pour l'attention

### Quand le texte est acceptable

| Acceptable | Non recommandé |
| --- | --- |
| Nom de marque/logo | Répéter le texte du titre |
| Appel à l'action court | Paragraphes de texte |
| Prix/remise (si message clé) | Conditions générales |
| Nom du produit | Informations de contact |

### Directives de texte (si utilisé)

| Directive | Mise en oeuvre |
| --- | --- |
| Couverture | Max 20% de la surface de l'image |
| Lisibilité | Grand, fort contraste, lisible en petite taille |
| Placement | Ne pas masquer les éléments visuels clés |
| Redondance | Ne pas dupliquer le texte du titre/de la description |

## Standards de qualité d'image

### Qualité technique

| Standard | Exigence |
| --- | --- |
| Résolution | Nette, pas pixelisée ou floue |
| Éclairage | Bien éclairée, pas sous-exposée ou surexposée |
| Mise au point | Sujet net |
| Couleur | Fidèle, pas sursaturée ou délavée |
| Compression | Artefacts de compression minimaux |

### Qualité créative

| Standard | Mise en oeuvre |
| --- | --- |
| Pertinence | L'image correspond au produit/service et à l'audience |
| Cohérence de marque | Alignée avec l'identité visuelle de la marque |
| Attrait émotionnel | Évoque le sentiment approprié pour l'objectif |
| Différenciation | Se distingue de l'imagerie concurrente |
| Authenticité | Réelle/crédible, pas trop "stock" |

## Contenu interdit

### Violations de politique Google Ads

| Interdit | Exemples |
| --- | --- |
| Contenu trompeur | Faux boutons, fausses notifications, allégations trompeuses |
| Contenu choquant | Violence, gore, images perturbantes |
| Contenu adulte | Imagerie sexuelle, nudité |
| Produits dangereux | Armes, drogues, tabac |
| Produits contrefaits | Faux produits de marque |
| Contenu discriminatoire | Contenu ciblant des groupes protégés |

### Déclencheurs courants de refus

| Déclencheur | Comment éviter |
| --- | --- |
| Boutons simulés | N'ajoutez pas de faux boutons "Play", "Télécharger" ou "Cliquer" |
| Avant/après | Évitez les images de transformation irréalistes |
| Texte excessif | Gardez le texte sous 20% de l'image |
| Qualité basse | Utilisez des images haute résolution, professionnelles |
| Contenu trompeur | Assurez-vous que l'image représente fidèlement l'offre |

## Types d'images par objectif

### Images centrées produit

| Cas d'usage | Bonnes pratiques |
| --- | --- |
| Ecommerce | Photos produit épurées, fonds blancs/simples |
| Photos héros | Produit comme sujet principal, contexte lifestyle optionnel |
| Photos de détail | Gros plans sur les fonctionnalités clés, indicateurs de qualité |
| Référence d'échelle | Produit en contexte montrant la taille/l'utilisation |

### Images lifestyle

| Cas d'usage | Bonnes pratiques |
| --- | --- |
| Personnes utilisant le produit | Scénarios authentiques, sujets auxquels on peut s'identifier |
| Aspirationnel | Résultat/style de vie souhaité avec le produit |
| Problème/solution | Visualisation de l'état avant ou de l'état résolu |
| Émotionnel | Visages montrant l'émotion pertinente |

### Images de marque

| Cas d'usage | Bonnes pratiques |
| --- | --- |
| Notoriété de marque | Couleurs de marque fortes, logo proéminent |
| Imagerie de campagne | Langage visuel cohérent entre les annonces |
| Saisonnier | Imagerie opportune (fêtes, événements) |

## Erreurs courantes

| Erreur | Problème | Solution |
| --- | --- | --- |
| Un seul ratio | Emplacements manqués, portée limitée | Créez tous les ratios requis |
| Basse résolution | Pixelisé sur les grands écrans | Utilisez 1200 px minimum |
| Images chargées de texte | Risque de politique, mauvaise performance | Minimisez le texte, utilisez le texte d'annonce à la place |
| Fonds chargés | Distrayants, message flou | Utilisez des fonds épurés, simples |
| Pas de point focal clair | Confus, oubliable | Sujet unique, hiérarchie claire |
| Photos stock génériques | Inauthentiques, faible engagement | Utilisez de la photographie réelle/personnalisée |
| Logo trop petit | Non visible en petite taille | Testez à 50×50 px |
| Contenu critique aux bords | Rogné sur certains emplacements | Gardez les éléments clés dans le centre 80% |
| Branding incohérent | Confus, non professionnel | Maintenez la cohérence visuelle |
| Améliorations d'image activées | Dégradation de la qualité | Désactivez - créez vous-même toutes les tailles |
