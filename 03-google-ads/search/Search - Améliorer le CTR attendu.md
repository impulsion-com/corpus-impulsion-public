# Améliorer le CTR attendu

> **Plateforme :** Google Ads
> **Catégorie :** Search
> **Type :** SOP
> **Mis à jour :** 2026-05-07

## Phase 1️⃣: Diagnostiquer

### 1.1 Le test des 5 secondes

Avant de plonger dans une analyse détaillée, faites cette vérification rapide de bon sens.

Lisez votre annonce à voix haute. Un inconnu devrait pouvoir répondre à ces questions en 5 secondes :

| Question | Si Non → Lacune |
| --- | --- |
| Que proposez-vous ? | Proposition de valeur absente/faible |
| Pourquoi devrais-je m'y intéresser ? | Bénéfice/USP absent/faible |
| Pourquoi devrais-je vous faire confiance ? | Preuve sociale absente |
| Que dois-je faire ? | CTA absent/faible |
| Pourquoi vous plutôt que les concurrents ? | Différenciation absente |
| Pourquoi agir maintenant ? | Urgence / Suppression du risque absente |

> Si votre annonce échoue à **2+ questions,** vous avez déjà identifié vos **lacunes prioritaires.**

---

### 1.2 Checklist de base de la RSA

Votre RSA doit inclure ces éléments pour être compétitive :

| Élément | Question | Si absent → |
| --- | --- | --- |
| **Ancrage de pertinence** | La RSA contient-elle le mot-clé/la racine sémantique ? | Lancez [SOP - Ameliorer la pertinence des annonces](<Search - Améliorer la pertinence des annonces.md>) |
| **Proposition de valeur claire** | Un chercheur peut-il comprendre ce que vous offrez en 3 secondes ? | Lancez [SOP - Creer vos angles d'offre](<../../01-strategie/offre/Offre - Travailler vos angles d'offre.md>) → [Headline Angle Catalog](<Search - Angles de headlines.md>) |
| **Appel à l'action** | Y a-t-il une action claire à faire pour le chercheur ? | Lancez [Headline Angle Catalog](<Search - Angles de headlines.md>) (section CTA) |
| **Différenciation** | Y a-t-il une raison de vous choisir plutôt que les concurrents ? | Lancez [SOP - Creer une offre irresistible](<../../01-strategie/offre/Offre - Créer une offre irrésistible.md>) → [SOP - Creer vos angles d'offre](<../../01-strategie/offre/Offre - Travailler vos angles d'offre.md>) |
| **Signal de crédibilité** | Y a-t-il une preuve que vous pouvez livrer ? | Lancez [SOP - Creer vos angles d'offre](<../../01-strategie/offre/Offre - Travailler vos angles d'offre.md>) (preuve sociale) |
| **Réducteur de risque** | Y a-t-il quelque chose qui abaisse la barrière à l'action ? | Lancez [SOP - Creer vos angles d'offre](<../../01-strategie/offre/Offre - Travailler vos angles d'offre.md>) (suppression du risque) |

### 1.3 Analyse des lacunes de la RSA

**Action :**

1. Ouvrez votre RSA dans le groupe d'annonces.
2. Listez tous les titres et descriptions actuels.
3. Taguez chaque composant avec son type :
    - Ancrage de pertinence
    - Proposition de valeur
    - Appel à l'action
    - USP / Bénéfice
    - Preuve sociale
    - Suppression du risque
4. Identifiez quels types sont absents ou faibles.

---

### 1.4 Audit des concurrents

**Objectif :** Comprendre à quoi vous vous mesurez.

**Action :**

1. Vérifiez les Insights sur les enchères → **Taux de chevauchement (Overlap Rate)** pour identifier les principaux concurrents (voir capture ci-dessous).
2. Recherchez vos principaux mots-clés dans un navigateur en navigation privée, ou utilisez le [**Google's Ads Transparency Center**](https://adstransparency.google.com/).
3. Faites une capture des 3-4 principales annonces concurrentes.
4. Notez ce qu'ils font que vous NE faites PAS.

#### Ce qu'il faut chercher :

| Pattern | Implication |
| --- | --- |
| Tout le monde utilise le même angle | Prérequis de base : il vous le faut aussi |
| Un concurrent a un angle qui vous manque | Lacune dans votre RSA |
| Vous avez un angle que personne d'autre n'a | Opportunité de différenciation : mettez-le en avant |
| L'angle est vague chez tous les concurrents | Opportunité d'être spécifique |

### 1.5 Lacunes courantes qui causent un CTR attendu "Below Average"

| Lacune | Symptôme | SOP cause racine |
| --- | --- | --- |
| **Aucun bénéfice spécifique** | Les titres disent ce que vous ÊTES, pas ce que vous FAITES pour eux | [SOP - Creer vos angles d'offre](<../../01-strategie/offre/Offre - Travailler vos angles d'offre.md>) |
| **Aucune preuve sociale** | Pas de notes, de nombres d'utilisateurs, ni de signaux de crédibilité | [SOP - Creer vos angles d'offre](<../../01-strategie/offre/Offre - Travailler vos angles d'offre.md>) |
| **CTA faible** | "Contact Us" ou "Learn More" | [Headline Angle Catalog](<Search - Angles de headlines.md>) |
| **Aucune différenciation** | Les mêmes promesses génériques que chaque concurrent | [SOP - Creer une offre irresistible](<../../01-strategie/offre/Offre - Créer une offre irrésistible.md>) |
| **Aucune inversion du risque** | Rien qui n'abaisse la barrière d'engagement | [SOP - Creer vos angles d'offre](<../../01-strategie/offre/Offre - Travailler vos angles d'offre.md>) |
| **Texte centré sur soi** | "We offer..." / "Our solution..." | [Headline Angle Catalog](<Search - Angles de headlines.md>) |
| **Promesses vagues** | "Quality solutions", "Great service" | [Headline Angle Catalog](<Search - Angles de headlines.md>) |
| **Aucun chiffre** | Zéro promesse quantifiée | [SOP - Creer vos angles d'offre](<../../01-strategie/offre/Offre - Travailler vos angles d'offre.md>) |
| **Les descriptions répètent les titres** | Le même message avec d'autres mots | [Description Expansion Catalog](<Search - Patterns d'expansion de descriptions.md>) |
| **Extensions manquantes** | Pas de liens annexes, accroches, images | [Extension Leverage Catalog](<../composants/Composants - Utilisation des extensions.md>) |
| **Offre faible** | Rien de convaincant à dire 💩 | [SOP - Creer une offre irresistible](<../../01-strategie/offre/Offre - Créer une offre irrésistible.md>) |

## Phase 2️⃣: Router et exécuter

En fonction de votre liste de lacunes, lancez les SOP fondamentales appropriées.

#### Arbre de décision

```
Votre OFFRE est-elle faible ou indifférenciée ?
│
├─ OUI → Lancez : Créer une offre irrésistible
│         Puis : Travailler vos angles d'offre
│         Puis : Rédiger les titres + Rédiger les descriptions
│
└─ NON → Vos ANGLES sont-ils documentés ?
        │
        ├─ NON → Lancez : Travailler vos angles d'offre
        │        Puis : Rédiger les titres + Rédiger les descriptions
        │
        └─ OUI → Quels éléments manquent ?
                 │
                 ├─ Titres faibles → Lancez : Rédiger les titres
                 ├─ Descriptions faibles → Lancez : Rédiger les descriptions
                 ├─ Extensions manquantes → Lancez : Ajouter des extensions convaincantes
                 └─ Plusieurs lacunes → Lancez toutes les procédures applicables
```

---

#### Ordre d'exécution

Si plusieurs lacunes existent, suivez cet ordre :

1. **[SOP - Creer une offre irresistible](<../../01-strategie/offre/Offre - Créer une offre irrésistible.md>)** (si l'offre est le problème)
2. **[SOP - Creer vos angles d'offre](<../../01-strategie/offre/Offre - Travailler vos angles d'offre.md>)** (extraire/rafraîchir les angles)
3. **[Headline Angle Catalog](<Search - Angles de headlines.md>)** (créer/améliorer les titres)
4. **[Description Expansion Catalog](<Search - Patterns d'expansion de descriptions.md>)** (créer/améliorer les descriptions)
5. **[Extension Leverage Catalog](<../composants/Composants - Utilisation des extensions.md>)** (combler les manques d'extensions)

## Phase 3️⃣: Valider

### 3.1 Surveiller le CTR attendu

**Calendrier :**

- **7 jours :** Vérifiez le premier mouvement de CTR
- **14-21 jours :** Vérifiez le label Expected CTR du Niveau de qualité

#### Checklist de validation :

| Échéance | Métrique | Cible |
| --- | --- | --- |
| 7 jours | CTR absolu | En hausse |
| 14 jours | Label Expected CTR | Plus « Below Average » |
| 21 jours | Label Expected CTR | Stable à « Average » ou au-dessus |

---

### 3.2 Si l'Expected CTR ne s'améliore pas

| Situation | Action |
| --- | --- |
| Le CTR s'est amélioré mais le label est inchangé | Attendre plus longtemps (les labels sont en retard) |
| CTR plat après 14 jours | Relancer le diagnostic de la Phase 1 ; quelque chose a été manqué |
| Le CTR a chuté | Vérifier d'autres changements (enchères, concurrence, page de destination) |
| Label bloqué à « Average » | « Average » est acceptable ; passez à [SOP - Test RSA avec la boucle d'iteration](<Search - Test RSA avec la boucle d'itération.md>) |

---

### Validation et critères de complétion

#### Définition du terminé

Cette SOP est terminée quand :

- [ ]  La RSA passe la checklist de base (tous les éléments présents)
- [ ]  La RSA a une différenciation claire par rapport aux concurrents
- [ ]  Les extensions sont complètes et approuvées
- [ ]  Les composants automatisés sont configurés correctement
- [ ]  Expected CTR ≠ *Below Average* pendant **14 jours consécutifs**

#### Passerelle de sortie

Une fois terminée, vous avez deux chemins :

- **Chemin A : Expected CTR = Average, vous voulez optimiser davantage**
    
    → Continuer vers [SOP - Test RSA avec la boucle d'iteration](<Search - Test RSA avec la boucle d'itération.md>)
    
- **Chemin B : Expected CTR = Average, Landing Page Experience = Below Average**
    
    → Continuer vers [SOP - Ameliorer l'experience de la page de destination](<../../02-site-web/audit/Audit - Test A-B de Landing Page.md>)
    

> ⚠️ **L'amélioration continue de l'Expected CTR** passe par [SOP - Test RSA avec la boucle d'iteration](<Search - Test RSA avec la boucle d'itération.md>), pas par des exécutions répétées de cette SOP. Cette SOP est un diagnostic et une réparation ponctuels. La boucle d'itération est la méthode d'optimisation continue.

### FAQ

**Q : En quoi est-ce différent de l'ancienne version de cette SOP ?**

R : L'ancienne version incluait tout le contenu « comment rédiger ». Cette version se concentre sur le diagnostic et vous redirige vers des SOP modulaires pour l'exécution. Même résultat, meilleure organisation.

**Q : Et si je ne sais pas si mon offre est faible ?**

R : Déroulez l'Offer Audit Checklist dans [SOP - Creer une offre irresistible](<../../01-strategie/offre/Offre - Créer une offre irrésistible.md>). Si vous obtenez moins de 8/12, votre offre a besoin de travail avant que l'optimisation créative ne serve à quelque chose.

**Q : Puis-je sauter les SOP fondamentales et juste rédiger de nouveaux titres ?**

R : Vous pouvez, mais vous répéterez probablement les mêmes erreurs. Les SOP fondamentales garantissent que vous avez la bonne matière première (les angles) avant de rédiger.

**Q : Et si l'Expected CTR est « Average » : dois-je quand même lancer ceci ?**

R : Non. « Average » est acceptable. Continuez directement vers [SOP - Test RSA avec la boucle d'iteration](<Search - Test RSA avec la boucle d'itération.md>) pour l'optimisation continue.

**Q : Combien de temps avant que l'Expected CTR s'améliore ?**

R : 14-21 jours pour que le label se mette à jour. Le mouvement de CTR apparaît dans les 7 premiers jours.
