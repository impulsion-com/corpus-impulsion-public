# Rechercher des mots-cles

> **Plateforme :** Google Ads
> **Catégorie :** Search
> **Type :** SOP
> **Mis à jour :** 2026-05-07

## Phase 1️⃣ : Contextualiser

### 1.1 Documenter le contexte business

Avant d'ouvrir un quelconque outil, répondez à ces questions. Enregistrez les réponses dans un spreadsheet ou un document :

1. **Que vend l'entreprise ?** Listez tous les produits/services à promouvoir.
2. **Qui est l'audience cible ?** Démographie, pain points, déclencheurs d'achat.
3. **Quels sont les USP ?** Points de différenciation uniques par rapport aux concurrents.
4. **Quels sont les objectifs de conversion ?** Leads, ventes, démos, inscriptions.
5. **Quels produits/services sont les plus prioritaires ?** Classez par potentiel de revenu ou importance stratégique.

### 1.2 Construire la liste de seed keywords

Générez 10-30 seed keywords à partir de trois sources :

**Source A : Offres de l'entreprise**

1. Notez les noms principaux des produits/services.
2. Ajoutez les variations courantes utilisées par les clients (pas le jargon métier).
3. Incluez les termes de marque si vous prévoyez des campagnes brand.

**Source B : Contenu du site web**

1. Passez en revue la homepage, les pages produits/services et les landing pages.
2. Notez les termes principaux utilisés dans les titres de page, les H1 et les meta descriptions.
3. Ajoutez tous les termes pour lesquels le site se positionne organiquement et qui indiquent une intention d'achat.

**Source C : Sites concurrents**

1. Visitez 2-3 sites de concurrents.
2. Notez comment ils décrivent des produits/services similaires.
3. Ajoutez les termes qu'ils utilisent que l'entreprise n'utilise pas.

### 1.3 Enregistrer les seed keywords

Créez un spreadsheet avec ces colonnes :

| Colonne | Description |
|--------|-------------|
| Seed Keyword | Le terme |
| Source | D'où il vient (business, site web, concurrent) |
| Produit/Service prioritaire | Quelle offre il couvre |

**Cible : 10-30 seed keywords couvrant tous les produits/services prioritaires.**

> **Vérification :** Chaque produit/service prioritaire a au moins 2 seed keywords. Sinon, revenez à l'étape 1.2.

## Phase 2️⃣ : Générer les keywords avec les outils

Utilisez les cinq sources ci-dessous. Chaque source fait remonter des types de keywords différents. Sauter une source laisse des trous.

### 2.1 Google Keyword Planner

Google Keyword Planner est votre outil de recherche first-party principal. Il propose deux méthodes de découverte : démarrer avec des keywords ou démarrer avec un site web.

**Méthode A : Démarrer avec des keywords**

1. Ouvrez Google Ads > Outils > Keyword Planner > "Découvrir de nouveaux keywords" > "Démarrer avec des keywords".
2. Entrez 3-5 seed keywords à la fois (groupés par produit/service).
3. Optionnellement, entrez votre domaine : Google va essayer d'exclure les keywords non liés à ce que vous proposez.
4. Passez en revue la liste d'idées de keywords.
5. Appliquez les filtres :
   - Définissez le ciblage géographique sur votre marché cible.
   - Définissez la langue sur votre langue cible.
   - Retirez les keywords avec un volume de recherche à zéro.
6. Triez par "Recherches mensuelles moyennes" (décroissant).
7. Sélectionnez toutes les idées de keywords pertinentes.
8. Téléchargez la liste (CSV ou Google Sheets).
9. Répétez pour chaque groupe de seed keywords.

**Méthode B : Démarrer avec un site web**

1. Ouvrez Google Ads > Outils > Keyword Planner > "Découvrir de nouveaux keywords" > "Démarrer avec un site web".
2. Entrez l'URL de votre propre site (ou l'URL d'un concurrent) pour découvrir des keywords basés sur le contenu de la page.
3. Choisissez "Utiliser tout le site" ou "Utiliser uniquement cette page" selon le périmètre.
4. Passez en revue les idées de keywords générées. Google analyse le contenu de la page pour trouver des keywords pertinents (le contenu des liens hypertextes n'est pas utilisé pour la génération de keywords).
5. Appliquez les mêmes filtres que la Méthode A (localisation, langue, volume).
6. Téléchargez la liste.
7. Répétez pour les sites de concurrents (2-3 minimum).

> 💡 **Faites les deux méthodes :** Démarrer avec des keywords fait remonter des termes que vous connaissez déjà. Démarrer avec un site web fait remonter des termes que vous avez ratés, surtout depuis les sites concurrents.

> **Vérification :** Vous avez au moins un export Keyword Planner par produit/service prioritaire, en utilisant la découverte par keywords et celle par site web.

### 2.2 Autocomplete Google Search et recherches associées

Pour chaque seed keyword :

1. Ouvrez Google Search dans une fenêtre incognito/privée.
2. Tapez le seed keyword lentement et notez toutes les suggestions d'autocomplete.
3. Appuyez sur Entrée et scrollez en bas de la page de résultats.
4. Enregistrez toutes les suggestions de "Recherches associées".
5. Cliquez dans les boîtes "Autres questions posées" et enregistrez les questions.
6. Ajoutez tous les nouveaux termes à votre liste de keywords brute.

> **Astuce :** L'autocomplete fait remonter des variations long-tail que Keyword Planner rate souvent. Ce sont des requêtes réelles que les gens tapent.

### 2.3 SEMrush (ou outil concurrentiel équivalent)

**Keyword Magic Tool :**

1. Ouvrez SEMrush > Keyword Magic Tool.
2. Entrez chaque seed keyword.
3. Passez en revue l'arbre de keywords et les sous-thèmes.
4. Filtrez par volume de recherche (définissez un minimum basé sur la taille de votre marché).
5. Exportez les keywords pertinents.

**Analyse des keywords concurrents :**

1. Ouvrez SEMrush > Domain Overview.
2. Entrez 2-3 domaines de concurrents.
3. Naviguez vers "Organic Research" > "Positions" pour les idées de keywords organiques.
4. Naviguez vers "Advertising Research" > "Positions" pour les idées de keywords payants.
5. Exportez les keywords sur lesquels vos concurrents enchérissent et que vous n'avez pas encore capturés.

**Analyse de gap de keywords :**

1. Ouvrez SEMrush > Keyword Gap.
2. Entrez votre domaine et 2-3 domaines de concurrents.
3. Filtrez pour montrer les keywords sur lesquels les concurrents se positionnent et pas vous.
4. Exportez les keywords de gap.

> **Vérification :** Vous avez des exports depuis Keyword Magic Tool et au moins une analyse concurrentielle.

### 2.4 Keywordtool.io (ou outil long-tail équivalent)

1. Ouvrez Keywordtool.io.
2. Sélectionnez "Google" comme plateforme.
3. Entrez chaque seed keyword.
4. Définissez langue et localisation pour correspondre à votre marché cible.
5. Passez en revue les variations long-tail générées.
6. Exportez toutes les variations pertinentes.

> **Astuce :** Cet outil génère des variations à partir des données d'autocomplete Google sur plusieurs patterns de modifieurs (questions, prépositions, comparaisons). Il fait remonter des keywords long-tail riches en intention.

### 2.5 ChatGPT ou outils IA

Utilisez l'IA pour brainstormer des angles que vous avez ratés :

1. Donnez à l'IA : description de l'entreprise, produits/services, audience cible, seed keywords existants.
2. Demandez : termes de recherche associés, synonymes, variations long-tail, keywords sous forme de questions, keywords problem-aware.
3. Passez en revue la sortie et ajoutez les termes pertinents à votre liste brute.
4. Demandez quels keywords un concurrent dans cet espace ciblerait.
5. Ajoutez tout nouveau terme pertinent.

> **Attention :** Les keywords générés par IA nécessitent une validation de volume. Ne les ajoutez pas à la liste finale sans vérifier le volume de recherche réel en Phase 4.

## Phase 3️⃣ : Exploiter les rapports de termes de recherche

> **Sautez cette phase si le compte est tout neuf sans données historiques.**

### 3.1 Sortir le rapport sur les termes de recherche

1. Ouvrez Google Ads > Rapports > Termes de recherche.
2. Définissez la plage de dates : 90 derniers jours (ou maximum disponible).
3. Ajoutez les colonnes : Terme de recherche, Impressions, Clics, Conversions, Valeur de conversion.
4. Triez par Conversions (décroissant).

### 3.2 Extraire les candidats keywords

Identifiez les termes de recherche qui répondent à ces critères :

| Critère | Seuil |
|----------|-----------|
| A des conversions | 1 ou plus |
| A des impressions significatives | 50+ sur la période |
| Pas déjà un keyword | Vérifier contre la liste de keywords actuelle |
| Pas un close variant d'un keyword existant | Racine différente ou modifieur significatif |

### 3.3 Ajouter à la liste brute

1. Exportez les termes de recherche qualifiés.
2. Ajoutez-les à votre liste de keywords brute avec la source marquée "STR".
3. Notez les données de conversion à côté de chaque terme pour la priorisation lors du clustering.

> **Vérification :** Tous les termes de recherche convertisseurs pas déjà capturés comme keywords ont été passés en revue et les termes pertinents ajoutés.

## Phase 4️⃣ : Compiler et dédupliquer

### 4.1 Fusionner toutes les sources

1. Combinez tous les exports et les keywords enregistrés manuellement dans un seul spreadsheet.
2. Utilisez une ligne par keyword.
3. Incluez une colonne "Source" indiquant d'où vient chaque keyword.

### 4.2 Dédupliquer

1. Normalisez tous les keywords en minuscules.
2. Retirez les doublons exacts.
3. Retirez les quasi-doublons (singulier/pluriel, changements d'ordre de mots mineurs).
4. Gardez la version avec le plus haut volume de recherche en retirant les quasi-doublons.

### 4.3 Ajouter les métriques

Pour chaque keyword unique, assurez-vous que ces colonnes sont remplies :

| Colonne | Source |
|--------|--------|
| Keyword | Liste fusionnée |
| Volume de recherche mensuel moyen | Keyword Planner ou SEMrush |
| CPC moyen | Keyword Planner ou SEMrush |
| Niveau de concurrence | Keyword Planner (Faible/Moyen/Élevé) |
| Source | Quel(s) outil(s) ont fait remonter ce keyword |

**Pour remplir les métriques manquantes :**

1. Copiez jusqu'à 1 000 keywords à la fois dans Google Keyword Planner > "Obtenir le volume de recherche et les prévisions".
2. Téléchargez les résultats.
3. Fusionnez les données de volume et de CPC dans votre liste maître.

### 4.4 Étiqueter le type d'intention

Pour chaque keyword, assignez une étiquette d'intention :

| Type d'intention | Signal | Exemple |
|-------------|--------|---------|
| Transactionnelle | Contient "buy", "order", "purchase", "pricing", "cost" | "buy crm software" |
| Commerciale | Contient des termes de comparaison/évaluation : "best", "vs", "review", "top" | "best crm for small business" |
| Informationnelle | Contient "how to", "what is", "guide", "tutorial" | "what is a crm" |
| Navigationnelle | Contient des noms de marque ou des noms de produits spécifiques | "salesforce pricing" |

> **Astuce :** Focalisez-vous sur les keywords à intention transactionnelle et commerciale pour les campagnes Search. Étiquetez les keywords informationnels pour exclusion potentielle ou traitement en campagne séparée.

### 4.5 Nettoyage final

1. Retirez les keywords avec un volume de recherche à zéro (sauf s'ils viennent du rapport sur les termes de recherche avec des conversions).
2. Retirez les termes manifestement non pertinents qui ont glissé.

> **Vérification :** Chaque keyword dans la liste finale a des données de volume de recherche, une estimation de CPC, et une étiquette d'intention.

---

### Validation et critères de complétion

Cette SOP est terminée quand :

- [ ] Le contexte business est documenté (produits, audience, USP, objectifs)
- [ ] La liste de seed keywords est créée avec 10-30 termes couvrant tous les produits/services prioritaires
- [ ] Les exports Google Keyword Planner sont complétés pour tous les groupes de seed keywords
- [ ] L'autocomplete Google Search et les recherches associées sont capturées
- [ ] L'expansion de keywords SEMrush (ou équivalent) et l'analyse concurrentielle sont complétées
- [ ] Les variations long-tail Keywordtool.io (ou équivalent) sont capturées
- [ ] Les idées de keywords générées par IA sont passées en revue et les termes pertinents ajoutés
- [ ] Le rapport sur les termes de recherche est exploité (si compte existant)
- [ ] Toutes les sources sont fusionnées dans une liste maître unique
- [ ] Les doublons et quasi-doublons sont retirés
- [ ] Les données de volume de recherche et de CPC sont remplies pour tous les keywords
- [ ] Le type d'intention est étiqueté pour chaque keyword
- [ ] Les termes non pertinents et les évidents négatifs sont retirés

### Erreurs fréquentes

| Erreur | Pourquoi ça arrive | Comment l'éviter |
|---------|----------------|--------------|
| S'appuyer sur un seul outil de keywords | Chaque outil fait remonter des types de keywords différents : un seul outil laisse des trous | Utiliser les cinq sources de la Phase 2 |
| Sauter la recherche autocomplete | Rate les requêtes long-tail à forte intention que les utilisateurs réels tapent | Toujours faire la Phase 2.2 pour chaque seed keyword |
| Ajouter des keywords IA sans validation de volume | L'IA invente des termes plausibles que personne ne recherche | Valider chaque keyword généré par IA dans Keyword Planner |
| Ne pas dédupliquer avant le clustering | Une liste gonflée rend le clustering lent et propice aux erreurs | Toujours compléter la Phase 4.2 avant de passer en aval |
| Ignorer le rapport sur les termes de recherche | Rate des requêtes éprouvées et convertisseuses déjà dans le compte | Toujours faire la Phase 3 pour les comptes existants |
| Inclure des keywords informationnels sans les étiqueter | Gaspille le budget sur du trafic non convertisseur | Étiqueter l'intention en Phase 4.4 et séparer les termes informationnels |
