# Descriptions de produits

> **Plateforme :** Google Ads
> **Catégorie :** Flux Produit
> **Type :** SOP
> **Mis à jour :** 2026-05-07

## Fondamentaux des descriptions

### Limites de caractères et visibilité

| **Contexte** | **Visibilité** | **Implication** |
|-------------|---------------|-----------------|
| Onglet Shopping (visible) | 160 premiers caractères | Front-loader les infos clés |
| Description complète | 5000 max | Inclure tous les mots-clés pertinents |
| Annonce Shopping (PLA) | Non affichée | Utilisée uniquement pour la correspondance |

### Principes de description

- **Front-loader** les fonctionnalités clés dans les 160 premiers caractères
- **Inclure** les attributs pertinents (matériau, couleur, taille, fonctionnalités, bénéfices)
- **Être spécifique** plutôt que générique
- **Utiliser un langage naturel** avec des mots-clés pertinents
- **Pas de texte promotionnel** (cause des refus)

> 💡 Les descriptions sont un signal de correspondance secondaire. Bien que les titres aient plus d'impact, des descriptions bien optimisées peuvent vous aider à apparaître pour des requêtes pertinentes additionnelles.

---

## La formule de description fondamentale

**Formule universelle :**

`[Brand] presents [product], perfect for [target audience] who [user's need or desire]. This [product type] features [key feature 1], [key feature 2], and [key feature 3], making it [unique selling proposition].`

Cette formule assure que vous couvrez :
1. Identification de la marque et du produit
2. Audience cible
3. Fonctionnalités clés et spécifications
4. Proposition de valeur

## Modèles par catégorie

### Mode / Vêtements

**Modèle :**
```
Elevate your style with the [Brand] [Product Name]. This [product type] is designed for [target audience] who value [quality/comfort/style]. Made from [material], it features [feature 1], [feature 2], and [feature 3]. The [color] colorway pairs perfectly with [styling suggestion]. Available in size [size], it offers [fit type] fit for [comfort/mobility].
```

**Exemple :**
"Elevate your running performance with the Nike Air Zoom Pegasus 40 Women's Running Shoes. Designed for everyday runners who value comfort and responsiveness, these shoes feature Nike React foam cushioning, a breathable mesh upper, and a durable rubber outsole. The Black/White colorway pairs perfectly with any athletic wear. Available in size 8, they offer a true-to-size fit for all-day comfort during training runs and casual wear".

---

### Électronique

**Modèle :**
```
Experience [benefit] with the [Brand] [Product Name]. This [product type] delivers [key spec 1], [key spec 2], and [key spec 3]. Perfect for [use case], it features [feature 1] for [benefit 1] and [feature 2] for [benefit 2]. Compatible with [compatibility], this [product type] includes [what's in box]. The [color] finish complements any setup.
```

**Exemple :**
"Experience superior memory performance with the Corsair Vengeance RGB Pro 32GB DDR4 RAM. This desktop memory kit delivers 3200MHz speed, low latency timing, and dynamic RGB lighting. Perfect for gaming and content creation, it features aluminum heat spreaders for optimal cooling and Intel XMP 2.0 support for easy overclocking. Compatible with Intel and AMD platforms, this kit includes two 16GB modules. The black finish complements any high-performance build".

### Maison & Mobilier

**Modèle :**
```
Transform your [room] with the [Brand] [Product Name]. This [product type] combines [style] design with [functionality]. Crafted from [material], it measures [dimensions] to fit [space type]. Features include [feature 1], [feature 2], and [feature 3]. The [color] finish adds [aesthetic quality] to your space. [Assembly info].
```

**Exemple :**
"Transform your home office with the Flexispot E7 Standing Desk. This electric height-adjustable desk combines modern design with ergonomic functionality. Crafted from a sturdy steel frame and premium laminate top, it measures 55x28 inches to fit most workspaces. Features include a powerful dual-motor system, programmable height presets, and anti-collision technology. The black finish adds a professional touch to any room. Easy assembly with all hardware included".

### Santé & Beauté / Consommables

**Modèle :**
```
Support your [health goal] with [Brand] [Product Name]. This [product type] provides [key benefit] with [amount/serving] of [active ingredient]. Formulated for [target audience], it features [quality 1], [quality 2], and [quality 3]. Each [container type] contains [quantity] [format] for [duration] supply. [Usage instructions].
```

**Exemple :**
"Support your muscle recovery with Optimum Nutrition Gold Standard Whey Protein. This premium protein powder provides 24g of protein per serving with fast-absorbing whey isolates. Formulated for athletes and fitness enthusiasts, it features low fat, low sugar, and no fillers. Each 5lb container contains 74 servings for a 2.5-month supply. Mix one scoop with 6-8 oz of water or milk post-workout for optimal results. Chocolate flavor".

## Checklist d'éléments de description

Incluez ces éléments quand pertinent :

| **Élément** | **Pourquoi inclure** | **Exemple** |
|-------------|---------------------|-------------|
| **Marque + nom produit** | Identification, recherches de marque | "Nike Air Zoom Pegasus 40" |
| **Type de produit** | Correspondance de catégorie | "running shoes", "protein powder" |
| **Audience cible** | Signaux de pertinence | "athletes", "home cooks", "gamers" |
| **Fonctionnalités clés** | Correspondance + conversion | "noise cancelling", "waterproof" |
| **Spécifications** | Recherches techniques | "32GB", "5000 lumens", "100ml" |
| **Matériaux** | Signaux de qualité | "premium leather", "organic cotton" |
| **Dimensions** | Recherches de taille | "55x28 inches", "7 feet tall" |
| **Couleur** | Recherches de variantes | "Space Gray", "Navy Blue" |
| **Cas d'usage** | Correspondance d'intention | "perfect for gaming", "ideal for travel" |
| **Bénéfices** | Conversion | "all-day comfort", "fast results" |
| **Contenu du colis** | Clarté d'achat | "includes charger and case" |

## Erreurs courantes de descriptions

| **Erreur** | **Exemple** | **Pourquoi ça échoue** | **Correction** |
|-----------|-------------|----------------------|---------------|
| Trop courte | "Great product". | Pas de keywords de matching | Ajouter fonctionnalités, specs, bénéfices |
| Texte promotionnel | "50% off today! Best deal ever!" | Cause un refus | Supprimer le langage promotionnel |
| Liens | "Visit example.com for more" | Non autorisé dans les descriptions | Supprimer les liens |
| Balisage HTML | "<b>Great shoes</b>" | Non rendu, aspect laid | Utiliser du texte brut |
| Bourrage de keywords | "shoes running shoes athletic shoes" | Spam, peut être refusé | Utiliser un langage naturel |
| Générique | "High quality product you'll love" | Pas d'info spécifique | Ajouter des fonctionnalités spécifiques |
| Mauvais produit | Décrire des accessoires au lieu du produit principal | Confusant, correspondance non pertinente | Décrire uniquement le produit |

## Génération assistée par IA

Vous pouvez automatiser la création de descriptions en utilisant des outils IA (API ChatGPT, Gemini) avec cette structure de prompt :

**Modèle de prompt :**
```
Write a product description for Google Shopping using this information:
- Brand: [brand]
- Product: [product name]
- Product type: [category]
- Target audience: [who it's for]
- Key features: [feature 1], [feature 2], [feature 3]
- Specifications: [spec 1], [spec 2]
- Material: [material]
- Color: [color]
- Size: [size]

Requirements:
- Put most important info in first 160 characters
- No promotional language
- No links
- Natural language with relevant keywords
- Focus on features and benefits
```

> ⚠️ Revoyez toujours les descriptions générées par IA pour la précision et la conformité aux politiques avant la mise en ligne.
