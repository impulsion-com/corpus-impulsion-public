# Titres de produits

> **Plateforme :** Google Ads
> **Catégorie :** Flux Produit
> **Type :** SOP
> **Mis à jour :** 2026-05-07

## Fondamentaux des titres

### Limites de caractères

| **Visibilité** | **Caractères** | **Implication** |
|----------------|---------------|-----------------|
| Visible par l'utilisateur (PLA typique) | 70-100 | Front-loader les infos critiques |
| Titre complet | 150 max | Utiliser pour le matching de keywords |

### Principes de construction des titres

- **Front-loader** les détails les plus importants (marque, type de produit, attribut clé)
- **Utiliser les 150 caractères** quand possible pour un matching maximal
- **Inclure les attributs de variante** (couleur, taille) pour chaque variante
- **Pas de texte promotionnel** (cause des refus)
- **Pas de MAJUSCULES** pour l'emphase

> ⚠️ Google peut automatiquement réordonner votre titre pour matcher les recherches. Le front-loading reste important car il affecte ce que les utilisateurs voient.

---

## La formule de titre fondamentale

**Formule universelle :**

`[Marque] + [Type de produit] + [Attributs clés] + [Détails modèle/variante]`

Cette formule s'adapte par catégorie. L'ordre et les attributs spécifiques changent, mais le principe reste : les infos les plus importantes en premier.

## Formules par catégorie

### Mode / Vêtements

**Formule :** `Brand + Gender + Product Type + Attributes (color/size/material)`

| **Produit** | **Titre optimisé** | **Pourquoi ça fonctionne** |
|-------------|---------------------|---------------------------|
| Chaussures de course femme | "Nike Air Zoom Pegasus 40 Women's Running Shoes Black/White Size 8" | Marque + modèle + genre + type + couleur + taille |
| Veste homme | "The North Face Thermoball Eco Men's Jacket Navy Blue XL" | Marque + modèle + genre + type + couleur + taille |
| Robe femme | "Zara Midi Wrap Dress Women's Red Floral Print Size M" | Marque + type + genre + couleur + motif + taille |

**Attributs clés pour la mode :**

| **Attribut** | **Inclure quand** |
|-------------|-------------------|
| Genre | Toujours (men's, women's, unisex) |
| Couleur | Toujours |
| Taille | Toujours pour les variantes |
| Matériau | Quand pertinent (soie, coton, cuir) |
| Motif | Quand pertinent (floral, rayé, uni) |
| Style | Quand différenciant (midi, maxi, slim fit) |

### Électronique

**Formule :** `Brand + Attributes + Product Type + Model Number`

| **Produit** | **Titre optimisé** | **Pourquoi ça fonctionne** |
|-------------|---------------------|---------------------------|
| RAM | "Corsair Vengeance RGB Pro 32GB (2x16GB) DDR4 RAM 3200MHz Desktop Memory Kit Black" | Marque + capacité + specs + type + modèle |
| Laptop | "Apple MacBook Pro 14-inch M3 Pro 18GB RAM 512GB SSD Space Gray" | Marque + modèle + taille + specs + couleur |
| Casque | "Sony WH-1000XM5 Wireless Noise Cancelling Over-Ear Headphones Black" | Marque + modèle + fonctionnalités + type + couleur |

**Attributs clés pour l'électronique :**

| **Attribut** | **Inclure quand** |
|-------------|-------------------|
| Numéro de modèle | Toujours |
| Capacité/specs | Toujours (GB, TB, résolution) |
| Fonctionnalités clés | Quand différenciant (wireless, noise cancelling) |
| Compatibilité | Quand pertinent (for iPhone, for Windows) |
| Couleur | Quand plusieurs variantes |
| Génération | Quand pertinent (4th Gen, 2024) |

## Erreurs courantes de titres

| **Erreur** | **Exemple** | **Pourquoi ça échoue** | **Correction** |
|-----------|-------------|----------------------|---------------|
| Trop court | "Running shoes" | Pas de keywords de matching, pas de différenciation | Ajouter marque, modèle, attributs |
| Texte promotionnel | "50% OFF Nike Running Shoes" | Cause un refus | Supprimer le langage promotionnel |
| TOUT EN MAJUSCULES | "NIKE RUNNING SHOES" | Aspect non professionnel | Utiliser une capitalisation normale |
| Bourrage de keywords | "Shoes running shoes athletic shoes sports shoes" | Aspect spam, peut être refusé | Utiliser un langage naturel |
| Marque manquante | "Wireless noise cancelling headphones" | Recherches de marque manquées, moins de confiance | Ajouter la marque en premier |
| Mauvais ordre | "Black size 8 women's Nike running shoes" | Infos clés enterrées | Front-loader marque + type de produit |

## Gestion des titres de variantes

Quand vous avez des variantes de produit, chaque variante a besoin d'un titre unique avec ses attributs spécifiques :

| **Produit parent** | **Attribut de variante** | **Titre de variante** |
|-------------------|-----------------------|-----------------------|
| Nike Air Max 90 | Size 9, White | "Nike Air Max 90 Men's Sneakers White Size 9" |
| Nike Air Max 90 | Size 10, Black | "Nike Air Max 90 Men's Sneakers Black Size 10" |
| Nike Air Max 90 | Size 11, Red | "Nike Air Max 90 Men's Sneakers Red Size 11" |

> ⚠️ **Chaque variante doit avoir un titre unique :** N'utilisez pas le même titre pour toutes les variantes - les utilisateurs et Google ont besoin de savoir sur quelle variante ils cliquent.
